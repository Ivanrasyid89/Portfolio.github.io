# Customer Churn Classification
## Overview
This project analyzes how many customers have stopped using the service, examines customer behavior patterns, identifies groups that are potential targets for retention efforts, and evaluates the extent to which the analysis results can support business decisions

## Goals
1. Reduce Customer Churn
2. Improve Retention & Repeat Usage
3. Optimize Acquisition Channel

## Methodology
1. Business Understanding
2. EDA & Statistical Testing
3. Modelling & Validation
4. Business Evaluation

## Algorithms
1. Logistic Regression
2. Random Forest Classifier

## Key Findings
1. Churn in the dataset reached 29.6%, with 74 customers classified as churned out of a total of 250 customers
2. The number of transactions was the strongest predictor of behavior among the variables tested in the univariate analysis
3. Digital activity, average transaction value, age, city, and acquisition channel did not show sufficient statistical evidence to distinguish churn status in the tests conducted
4. Random Forest showed relatively better cross-validation results than Logistic Regression on most metrics, but its performance was not strong enough to be considered a production-ready churn model
